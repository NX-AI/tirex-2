# Security Policy

## Supported Versions

Only the latest released version of TiRex-2 is supported for security updates.

| Version | Supported |
| --- | --- |
| Latest release | :white_check_mark: |
| Older releases | :x: |

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately to [contact@nx-ai.com](mailto:contact@nx-ai.com).

We will acknowledge your report within 7 days and provide an update on its status within two weeks.
